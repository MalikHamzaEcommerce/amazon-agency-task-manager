MANAGER ROLE UPDATE

1. Extract this ZIP.
2. Upload all files to the SAME GitHub repository root and replace same-name files.
3. Commit changes.
4. Wait 1-2 minutes for GitHub Pages, then hard refresh (Ctrl+F5).
5. Firebase Console -> Firestore Database -> Rules.
6. Replace all current rules with the new firestore.rules and click Publish.
7. Owner -> Team / VAs -> Edit a VA -> Role: Manager -> Save.
8. Refresh the Manager login and test accounts/tasks/team access.

Important: Managers have full operational access, but only the Owner can grant/remove the Manager role or manage another Manager account.
